# Tasky

A Flutter application demonstrating authentication, task management, and
Firebase integration. The app provides login/register flows, a home screen
where users can add and track dated tasks with priorities, and a details
page for editing or deleting tasks.

---

## 🛠 Project Structure

- `lib/` – Dart source files
  - `core/` – helpers and utilities (validators, dialogs, asset paths,
    media query extensions, network state classes)
  - `featurs/` – grouped feature code
    - `auth/` – Firebase authentication and user model
    - `feature_login_screen/` – login UI and validation widgets
    - `feature_register/` – registration UI with validators
    - `feature_home_page/` – home screen, task CRUD, bottom sheet,
      priority selector, date picker, and related models
    - `details_page/` – task detail/edit/delete screen
- `assets/` – icons and images used throughout the UI
- Platform folders (`android/`, `ios/`, `web/`, `linux/`, `macos/`, `windows/`)
  contain the platform-specific configuration generated by Flutter
- `test/` – widget/unit tests (currently includes a sample test)

---

## ⚡ Features

1. **Firebase integration**
   - Authentication using `firebase_auth`
   - User data and tasks stored in Firestore under per-user collections
   - `firebase_options.dart` generated by `flutterfire` CLI
2. **Authentication flows**
   - Email/password login and registration with custom validators
   - Persistent login state on app launch
   - Logout implemented by deleting the user document and returning to
     login screen
3. **Task management**
   - Add tasks with title, description, due date (via calendar picker),
     and numeric priority
   - Tasks are fetched per selected date and separated into active/completed
     lists
   - Search bar filters tasks by title
   - Detail screen lets users mark tasks done, edit or delete tasks
   - Tasks sorted by priority and support swipe-to-complete in lists
4. **Shared utilities**
   - `Validator` class with email, password, name, phone, and code checks
   - `AppDialogue` for showing loading spinners and error alerts
   - `AppAssets` constants for icon/image paths
   - `MediaQueryExtension` to scale dimensions based on a Figma design
   - `Result<T>` sealed class representing success/error for network calls
5. **Custom widgets**
   - Text fields with built‑in validation for login/registration/home
   - Bottom sheet for adding tasks, including priority dialog
   - Date picker timeline on the home page

## 🚀 Getting Started

1. **Prerequisites**
   - Flutter SDK (>=3.x) and Dart (bundled)
   - Firebase CLI if you need to modify or emulate backend services

2. **Clone & install**
   ```bash
   git clone <repo-url>
   cd second_task
   flutter pub get
   ```

3. **Firebase configuration**
   - Ensure `google-services.json` (Android) and
     `Runner/GoogleService-Info.plist` (iOS) are present as in the repo.
   - If switching projects, regenerate `firebase_options.dart` via
     `flutterfire configure`.

4. **Run the app**
   ```bash
   flutter run
   ```

5. **Build for release**
   ```bash
   flutter build apk   # Android
   flutter build ios   # iOS (requires macOS)
   flutter build web   # Web
   ```

## 🧩 Notes

- Splash screen configuration is managed via
  `flutter_native_splash.yaml`.
- Tasks are stored in Firestore under `users/{uid}/tasks`.
- Design scaling uses a 390×844 reference screen, adjust constants in
  `MediaQueryExtension` if needed.
- Error/loading dialogs are non‑dismissable to prevent accidental UI
  interaction during network calls.
- The `Validator` helpers use simple regexes defined in
  `core/validator_helper/validators.dart`.
